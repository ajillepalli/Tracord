# Code of Conduct

Tracord should be a professional, practical, and safe place to build agentic software infrastructure.

## Expected Behavior

- Be direct and respectful.
- Critique ideas, designs, and code without attacking people.
- Assume trace data may contain sensitive information.
- Prefer reproducible evidence over vague claims.
- Make room for contributors with different experience levels.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing secrets, private prompts, private trace data, or credentials.
- Deliberately submitting unsafe examples that execute destructive actions without clear labeling and containment.
- Repeatedly ignoring maintainer guidance on security, privacy, or review process.

## Reporting

For conduct concerns, open a private maintainer contact path. For security concerns, follow [SECURITY.md](SECURITY.md).

Maintainers may remove comments, close issues, reject contributions, or block contributors to protect the project.
